## 🚀 Featured Projects

### 🛰️ [Asterion One — Desk-Scale Satellite Mission Simulator](https://github.com/HugoCeciliaHellin/Asterion_one2)
My BSc dissertation project. It's a satellite operations simulator designed to reproduce NASA-grade mission rigor on commodity hardware. I validated the system with over 370 automated tests and multiple fault-injection scenarios.
- **Highlights:** Predictive digital twin (Python/NumPy) for forecasting failures 15+ min ahead, resilient flight software with sub-second SAFE-state recovery, and a full observability stack (OpenTelemetry + Grafana).
- **Stack:** `Python` `Node.js` `PostgreSQL` `React` `Docker` `Ed25519`

### 🎾 [Padeliox — Padel Court Booking Platform](https://github.com/HugoCeciliaHellin/Padeliox-Tfg)
A full-stack web platform for booking padel courts, which I built as my final project for my Higher Vocational Training (DAW). It handles secure authentication, real-time bookings, and integrated payments.
- **Highlights:** JWT authentication with role-based access, Stripe payment integration, and a responsive React frontend with persistent sessions.
- **Stack:** `Node.js` `Express` `Sequelize` `MySQL` `React` `Stripe`
